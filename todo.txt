# TODO cho BE (backend) theo resource FE

1. Activities (Công việc, hoạt động)
- API lấy danh sách công việc theo các loại: được giao, hôm nay, quá hạn, sắp tới, tôi tạo, đã hoàn thành
- API filter động theo queryType
- API CRUD activity (create, read, update, delete)
- API gán người thực hiện, feedback, file, participants, liên kết kỳ học
- API lấy sub-activities
- Phân quyền: Chỉ người tạo, trưởng bộ môn, trưởng môn được sửa/xóa; người được giao chỉ được cập nhật trạng thái; các vai trò khác chỉ được xem.
- Business logic:
  + Không cho xóa activity nếu đã có file, feedback, hoặc đang liên kết với kỳ học.
  + Khi cập nhật trạng thái, gửi thông báo cho người liên quan.
  + Tự động chuyển trạng thái quá hạn nếu endTime < now và chưa completed.
  + Lưu lịch sử thay đổi trạng thái, người thực hiện.
  + Kiểm tra trùng lịch khi tạo/cập nhật activity.

2. Workspaces
- API CRUD workspace
- API phân quyền workspace: mỗi workspace có owner, admin, member, guest
- API thêm/xóa/sửa thành viên workspace, phân quyền từng thành viên
- Business logic:
  + Chỉ owner/admin được thêm/xóa/sửa thành viên, đổi tên workspace.
  + Member chỉ được xem và thao tác trong workspace được phân quyền.
  + Guest chỉ được xem dữ liệu public.
  + Khi xóa workspace, cần xác nhận và backup dữ liệu liên quan.
